# Endless Survival Defense 0.5.0

Minecraft **1.21.1 / Forge 52.1.15 / Java 21**용 협동 야생 생존 모드입니다. 전원이 한 번 준비하면 무한 웨이브가 자동 진행됩니다. 야생 채집·제작·건축을 유지하면서 **노드** 상점과 지속 업그레이드로 성장합니다.

## 설치와 조작

클라이언트와 서버에 같은 Forge 및 `build/libs/endlessdefense-0.5.0.jar`를 설치하세요. 모든 참가자의 모드 버전이 같아야 합니다.

| 키/명령 | 기능 |
| --- | --- |
| **G** | 최초 시작 전 준비/취소 |
| **H** | 진행 상태, 팀 부활, 참가자, **웨이브 포기 투표**, 관리자 설정 |
| **K** | 상점 |
| `/endlessdefense status` | 현재 상태 |
| `/endlessdefense surrender` | 포기 투표 찬성 |
| `/endlessdefense stop` | OP 권한 2 이상: 즉시 게임 종료 |

키는 **설정 → 조작 → 키 지정 → Endless Survival Defense**에서 바꿀 수 있습니다.

## 게임 진행과 포기

접속자 전원이 준비하면 일반 인벤토리·장비·엔더 상자를 비우고 오버월드 기본 스폰에 모입니다. 중요한 물품은 미리 월드에 보관하세요. 첫 웨이브 전에는 **11~60초** 동안 숨겨진 무작위 준비 시간이 흐릅니다. 마지막 10초에 타이틀과 효과음으로 카운트다운하며, 웨이브 시작·클리어 타이틀을 보여 줍니다. 이후 추가 준비 없이 자동 반복합니다. 접속자가 모두 나가면 대기 타이머는 멈춥니다.

휴식 시간은 5웨이브를 클리어할 때마다 조금씩 길어집니다. 기본값은 `최소 11 + 5웨이브당 2초`(상한 35초), `최대 60 + 5웨이브당 3초`(상한 100초)입니다. 예를 들어 시작 전 11~60초, 20웨이브 클리어 후 19~72초입니다. 정확한 종료 시각은 마지막 10초 전에는 알려 주지 않습니다.

**H 화면 아래쪽의 빨간 포기 투표**와 HUD 안내로 중간 종료를 찾을 수 있습니다. 접속 인원의 **과반수**가 찬성하면 전투를 중단하고 준비 단계로 돌아갑니다. 1명은 1표, 2명은 2표, 4명은 3표가 필요합니다. 표를 취소할 수 있고 로그아웃한 사람의 표는 제거됩니다. 포기하면 최고 웨이브 기록과 OP 설정은 유지하고 현재 게임의 노드·업그레이드·부활 횟수는 초기화합니다. 현재 인벤토리는 종료 시 유지되지만 다음 게임 시작 때 비웁니다.

진행 중 웨이브 적이 디스폰·언로드·추적 실패·시간 초과로 사라지면 **웨이브 번호를 올리지 않고 같은 웨이브를 재시도**합니다. 이때 클리어·처치·보스 보상과 전리품은 지급하지 않습니다. 서버 재시작 중이던 웨이브도 같은 번호로 재시도하며 이전 웨이브 적이 뒤늦게 로드되면 제거합니다.

## 적, 체력 바와 사운드

첫 웨이브 기본 적 수는 **1명 4마리, 2명 10마리, 4명 22마리**입니다. 인원·웨이브에 따라 증가하지만 총 128마리 상한이 있습니다. 생성은 플레이어에게 순서대로 할당합니다. 플레이어 주변 **9블록 이내**를 피하면서 지표면뿐 아니라 비슷한 높이의 동굴·나무 수관을 탐색합니다. 지하에 숨어 있고 가까운 적이 있으면 5초마다 최대 한 블록의 흙·돌·심층암을 파서 접근을 시도합니다. 블록 엔티티와 경도 3 초과 블록은 건드리지 않습니다.

3웨이브부터 스켈레톤, 4웨이브부터 **잿불 추적자**, 8웨이브부터 **철갑 수호자**가 섞이고, 5의 배수마다 철갑 수호자 보스가 나옵니다. 몹 체력은 `기본 체력 × OP 체력 설정 × min(3.4, 1 + 0.085 × (웨이브−1))`이며 보스에 1.8배, 최종 상한 300을 적용합니다. 공격력은 웨이브에 따라 최대 2배, 보스에 1.3배, 최종 상한 30입니다. 낮에 타 죽지 않도록 기본 좀비·스켈레톤에 투구를 지급합니다.

웨이브 적과 모드 커스텀 몹은 **지속 발광**하고 이름표에 10칸 체력 바와 현재/최대 체력이 표시됩니다. 체력이 줄면 초록→노랑→빨강으로 바뀝니다. 윤곽선은 보스 빨강, 철갑 수호자 금색, 잿불 추적자 하늘색, 스켈레톤 노랑, 일반 웨이브 좀비 흰색입니다. 일반 야생 몹에는 적용하지 않습니다. 정찰 업그레이드로 보스 예고·색상 범례·웨이브 체력 배율을 차례로 해금합니다.

웨이브 시작 시 경적과 바닐라 음반 **Ward** 배경음악, 마지막 10초 카운트다운 음, 클리어·종료 효과음이 재생됩니다. 클리어·재시도·종료 때 전투 음악을 정지합니다. 별도 음원이나 외부 에셋은 사용하지 않습니다.

웨이브 시작 시 오버월드 시간이 **13000~22999**면 야간으로 판정합니다. 기본 적 수의 15%를 추가하되 최대 16마리, 총 128마리 상한입니다. 밤이라는 이유로 체력·공격력을 함께 더 올리지는 않습니다.

## 노드 보상과 전리품

노드는 인벤토리 아이템이 아닌 플레이어별 월드 데이터입니다. 0.4 이전 저장의 화폐 잔액은 첫 로드에서 **10배로 한 번 환산**하고 업그레이드 레벨·기록을 유지합니다.

| 보상 | 기본 규칙 |
| --- | --- |
| 웨이브 클리어 | 1~5웨이브 **100/130/160/190/220 노드**, 6~20웨이브는 웨이브당 +60, 이후 제곱근 단계마다 +90. 예: 20웨이브 **1,120 노드** |
| 개인 처치 | 마지막 타격한 웨이브 적 **4마리마다 8 노드** |
| 보스 처치 | 접속 중 생존자마다 **150 노드** |
| 인챈트 전리품 | 마지막 타격자에게 기본 **10%** 확률로 무작위 인챈트 책. 웨이브 보정 후 최대 25%. 보스 마지막 타격 시 책 1개 보장 |

노드와 인챈트 책은 **웨이브 정상 클리어 때만** 확정 지급합니다. 적을 반복 생성하거나 디스폰시켜 처치 보상을 파밍할 수 없습니다. 개인 클리어 보상은 팀 인원수만으로 증가하지 않습니다. 마지막 타격 플레이어가 없으면 개인 처치·책은 지급되지 않습니다.

## 상점과 지속 업그레이드

K/H 상점에는 현재 노드·레벨·다음 단계 효과·가격·해금 웨이브·남은 재고가 표시됩니다. 구매 조건은 서버가 검사합니다. 강한 소모품 재고는 플레이어별·웨이브별로 새로 열립니다.

| 상품 | 가격·조건 |
| --- | --- |
| 채굴·체력·속도·방어·공격·회복 업그레이드 | 단계별 **30 / 100 / 300 / 850 / 2,000 노드**, 최대 5단계 |
| 정찰 업그레이드 | **30 / 100 / 300 노드**, 최대 3단계 |
| 빵×8 / 구운 소고기×8 / 횃불×32 | **30 / 60 / 40 노드** |
| 원목×32 / 조약돌×64 / 석재 벽돌×64 | **50 / 50 / 100 노드** |
| 돌 검 / 가죽 방어구 / 방패 / 화살×32 | **80 / 240 / 200 / 90 노드** |
| 철 주괴×8 / 랜턴×8 / 회복 물약×2 | **210 / 130 / 280 노드**, 뒤 둘은 3웨이브 해금 |
| 황금 사과 / 모루 / 거미줄×8 / 흑요석×16 | **350 / 500 / 520 / 650 노드**, 5/5/10/12웨이브 해금 및 재고 제한 |
| 철 / 다이아 장비 꾸러미 | **2,000 / 18,000 노드**, 1/12웨이브 해금 |
| 토템 / 마법 황금 사과 | **3,200 / 5,500 노드**, 20/30웨이브 해금, 각 웨이브 1회 |
| 종결 네더라이트 장비 | **10,000,000 노드**, 40웨이브 해금, 웨이브당 1회 |

구매한 지속 효과는 무한 유지하며 사망·재접속·차원 이동 후 계정 단계에서 복원합니다. 방어·공격 능력치는 고정 ID 수정자를 사용해 중복 누적을 막습니다. 회복 업그레이드는 10초마다 체력을 회복하고 3·5단계에서 재생 I·II가 추가됩니다. 장비 자체는 일반 바닐라 내구도·사망 규칙을 따릅니다.

## 팀 공유 부활

팀 전체가 하나의 부활 횟수를 공유합니다. 처음에는 1·2인 **4회**, 4인 **5회**이고 사망할 때 서버가 즉시 한 번 차감합니다. 0회에서 죽으면 관전자로 전환되며 기록된 팀원이 전원 탈락하면 게임 오버입니다. 부활 횟수는 웨이브마다 초기화되지 않고 6, 11, 16...웨이브 시작에 소량 보충됩니다. 15웨이브 이후 상한이 내려가고 30웨이브 이후 4인 팀도 총 1회 상한이 될 수 있습니다. 잔여 횟수·탈락자·팀원은 월드에 저장됩니다.

## OP 설정

권한 2 이상은 H 관리자 화면이나 `/endlessdefense config`에서 적 수·체력·공격력·탐지·방어·장비 확률을 조정할 수 있습니다. `/endlessdefense balance show`로 월드별 경제·휴식·야간·부활 설정을 볼 수 있습니다.

| `/endlessdefense balance` 항목 | 기본값 | 허용 범위 |
| --- | ---: | ---: |
| `early`, `earlyStep`, `mid`, `late` | 100, 30, 60, 90 | 10~1000, 0~200, 0~300, 0~500 |
| `killEvery`, `killBounty`, `boss` | 4, 8, 150 | 1~50, 0~100, 0~2000 |
| `enchantDrop` | 10% | 0~50% 기본 확률; 웨이브 보정 후 25% 상한 |
| `restMinStep`, `restMaxStep`, `restMaxCap` | 2, 3, 100초 | 0~10, 0~15, 60~180 |
| `night`, `nightCap` | 15%, 16마리 | 0~25%, 0~32 |
| `respawnCap`, `lateWave`, `grantInterval` | 8, 30, 5 | 1~20, 10~200, 2~20 |

예: `/endlessdefense balance early 100`. `ShopRules`에 상품 가격과 단계 비용, `BalanceRules`에 웨이브 공식, `WaveData`에 월드별 설정이 있습니다. 상품 가격 자체를 명령으로 바꾸는 기능은 없습니다.

## 빌드와 확인 범위

동봉 Gradle Wrapper를 사용합니다.

```powershell
java -version
.\gradlew.bat clean build --console=plain
.\gradlew.bat runGameTestServer --console=plain
```

실제 콘솔 결과와 미검증 사항은 [DEVELOPMENT_STATUS.md](DEVELOPMENT_STATUS.md)에 기록합니다. 클라이언트 화면·음악 재생·실제 멀티플레이는 콘솔 GameTest만으로 확인할 수 없으므로 게임 안에서 직접 확인해 주세요.
