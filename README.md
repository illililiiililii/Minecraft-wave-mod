# Endless Survival Defense 0.12.0

Minecraft **1.21.1 / Forge 52.1.15 / Java 21**용 협동 야생 생존 모드입니다. 전원이 한 번 준비하면 무한 웨이브가 자동 진행됩니다. 야생 채집·제작·건축을 유지하면서 **노드** 상점과 지속 업그레이드로 성장합니다.

## 설치와 조작

클라이언트와 서버에 같은 Forge 및 `build/libs/endlessdefense-0.12.0.jar`를 설치하세요. 모든 참가자의 모드 버전이 같아야 합니다.

| 키/명령 | 기능 |
| --- | --- |
| **G** | 최초 시작 전 준비/취소 |
| **H** | 진행 상태, 팀 부활, 참가자, **웨이브 포기 투표**, 관리자 설정 |
| **K** | 상점 |
| **J** | 주 손에 든 무기·방어구에 저장된 마력 주입 기회 1회 사용 |
| `/endlessdefense status` | 현재 상태 |
| `/endlessdefense surrender` | 포기 투표 찬성 |
| `/endlessdefense stop` | OP 권한 2 이상: 즉시 게임 종료 |

키는 **설정 → 조작 → 키 지정 → Endless Survival Defense**에서 바꿀 수 있습니다.

## 월드 만들기: 디펜스 야생 또는 일반 야생

**새 월드 생성 → 월드 탭 → 월드 유형**에서 **디펜스 야생**을 선택하면 바닐라 오버월드 지형·생물군계·동굴·자원·구조물 위에 시작 지점의 방어 거점을 한 번 만듭니다. **기본값**을 선택하면 기존처럼 일반 야생에서 플레이하며 방어 거점은 생성되지 않습니다. 두 월드 유형 모두 같은 웨이브·상점·업그레이드 규칙을 사용합니다. 이미 생성된 월드에는 생성 메뉴 선택을 소급 적용하지 않습니다.

디펜스 야생의 시작 지점에는 약 **39×39블록**의 평평한 안뜰, 네 방향의 폭 5블록 성문과 외부 진입로, 네 귀퉁이 감시탑, 사다리, 랜턴과 바닥 조명이 놓입니다. **중앙 봉화가 기지 핵심**이며 시작 위치는 봉화 옆으로 이동합니다. 거점 밖은 일반 야생으로 이어져 채집·건축할 수 있습니다. 플레이어가 거점 주변을 지킬 때 웨이브 적은 네 진입 방향 바깥쪽에 우선 생성되고, 적절한 위치를 찾지 못하면 기존 플레이어 주변 생성 규칙을 사용합니다. 생성 여부와 거점 좌표는 월드에 저장하여 재접속·웨이브 변경 때 거점을 다시 덮어쓰지 않습니다. 기존 디펜스 월드는 진행 중인 게임을 불러올 때 중앙 봉화를 한 번 배치합니다.

전용 서버에서는 월드 생성 전에 `server.properties`의 `level-type=endlessdefense:defense`로 선택할 수 있습니다. 일반 야생은 `level-type=minecraft:normal`을 사용하세요. 서버를 이미 만든 뒤 유형만 변경해도 기존 지형이 새 월드로 바뀌지는 않습니다.

## 게임 진행과 포기

접속자 전원이 준비하면 일반 인벤토리·장비·엔더 상자를 비우고 오버월드 기본 스폰에 모입니다. 중요한 물품은 미리 월드에 보관하세요. 첫 웨이브 전에는 **45~120초** 동안 숨겨진 무작위 준비 시간이 흐릅니다. 마지막 10초에 타이틀과 효과음으로 카운트다운하며, 웨이브 시작·클리어 타이틀을 보여 줍니다. 이후 추가 준비 없이 자동 반복합니다. 접속자가 모두 나가면 대기 타이머는 멈춥니다.

휴식 시간은 5웨이브를 클리어할 때마다 조금씩 길어집니다. 기본값은 `최소 45 + 5웨이브당 2초`(상한 90초), `최대 120 + 5웨이브당 3초`(상한 180초)입니다. 예를 들어 시작 전 45~120초, 20웨이브 클리어 후 53~132초입니다. 정확한 종료 시각은 마지막 10초 전에는 알려 주지 않습니다. 이전 버전 월드에서 `restMaxCap=100`으로 저장된 경우 그 상한은 유지되며 OP가 `/endlessdefense balance restMaxCap 180`으로 바꿀 수 있습니다.

**H 화면 아래쪽의 빨간 포기 투표**와 HUD 안내로 중간 종료를 찾을 수 있습니다. 접속 인원의 **과반수**가 찬성하면 전투를 중단하고 준비 단계로 돌아갑니다. 1명은 1표, 2명은 2표, 4명은 3표가 필요합니다. 표를 취소할 수 있고 로그아웃한 사람의 표는 제거됩니다. 포기하면 최고 웨이브 기록과 OP 설정은 유지하고 현재 게임의 노드·업그레이드·부활 횟수는 초기화합니다. 현재 인벤토리는 종료 시 유지되지만 다음 게임 시작 때 비웁니다.

진행 중 웨이브 적이 디스폰·언로드·추적 실패·시간 초과로 사라지면 **웨이브 번호를 올리지 않고 같은 웨이브를 재시도**합니다. 이때 클리어·처치·보스 보상과 마력 주입은 지급하지 않습니다. 서버 재시작 중이던 웨이브도 같은 번호로 재시도하며 이전 웨이브 적이 뒤늦게 로드되면 제거합니다.

## 적, 체력 바와 사운드

첫 웨이브 기본 적 수는 **1명 4마리, 2명 10마리, 4명 22마리**입니다. 이후 수는 웨이브 번호의 제곱근에 비례해 완만하게 늘고 증가분에 상한을 둡니다. **기본 전체 상한은 64마리**이며 OP가 조정할 수 있습니다. 보스 웨이브의 일반 적은 기본적으로 해당 웨이브 예상 수의 약 **50%**만 나오고 보스 1기가 추가됩니다. 생성은 플레이어에게 순서대로 할당합니다. 플레이어 주변 **10블록 이내**를 피하면서 지표면뿐 아니라 비슷한 높이의 동굴·나무 수관을 탐색합니다. 설산의 얇은 눈층은 아래 블록이 단단하면 생성 가능 바닥으로 인정하고, 무작위 탐색이 실패하면 더 넓은 범위와 일정 간격의 원형 위치를 탐색합니다. 끝내 실패할 경우 웨이브·좌표를 서버 로그에 남깁니다. 지하에 숨어 있고 가까운 적이 있으면 5초마다 최대 한 블록의 흙·돌·심층암을 파서 접근을 시도합니다. 블록 엔티티와 경도 3 초과 블록은 건드리지 않습니다.

3웨이브부터 스켈레톤, 4웨이브부터 **잿불 추적자**, 8웨이브부터 **철갑 수호자**, 10웨이브부터 둔화 공격의 **서리 감시자**, 16웨이브부터 **공성 거한**, 24웨이브부터 위더 공격의 **파멸 기사**가 섞입니다. 기본 5웨이브마다 보스 1기가 나옵니다. **5웨이브 잿불 선봉장**은 비교적 약하고, 10웨이브 철갑 수호자 → 15웨이브 서리 감시자 → 20웨이브 공성 거한 → 25웨이브 이후 파멸 기사 순으로 종류가 바뀝니다. 보스 웨이브 순서가 높을수록 체력·공격력 배율과 보상이 증가합니다. 일반 몹 체력은 `기본 체력 × OP 체력 설정 × min(3.4, 1 + 0.085 × (웨이브−1))`을 기준으로 하며 기본 개체 체력 상한은 300입니다. 보스는 별도 단계 배율과 단계에 따라 높아지는 상한을 사용합니다. 낮에 타 죽지 않도록 기본 좀비·스켈레톤에 투구를 지급합니다.

웨이브 적과 모드 커스텀 몹은 **지속 발광**합니다. **체력 바는 웨이브 적에게만** 이름표로 표시하며, 일반 야생 몬스터에게는 표시하지 않습니다. 10칸 바와 현재/최대 체력이 보이고 체력이 줄면 초록→노랑→빨강으로 바뀝니다. 윤곽선은 보스 빨강, 마력 주입자 보라, 철갑 수호자 금색, 잿불 추적자 하늘색, 서리 감시자 파랑, 공성 거한 진한 빨강, 파멸 기사 진한 보라, 웨이브 스켈레톤 노랑, 웨이브 좀비 흰색입니다. 정찰 업그레이드로 보스 예고·색상 범례·웨이브 체력 배율을 차례로 해금합니다.

웨이브 진행 중 배경음악은 재생하지 않습니다. 시작 경적, 마지막 10초 카운트다운 음, 클리어·종료 효과음만 유지합니다.

웨이브 시작 시 오버월드 시간이 **13000~22999**면 야간으로 판정합니다. 기본 적 수의 15%를 추가하되 최대 16마리, 기본 전체 상한 64마리를 넘지 않습니다. 밤이라는 이유로 체력·공격력을 함께 더 올리지는 않습니다.

## 노드 보상과 마력 주입

노드는 인벤토리 아이템이 아닌 플레이어별 월드 데이터입니다. 0.4 이전 저장의 화폐 잔액은 첫 로드에서 **10배로 한 번 환산**하고 업그레이드 레벨·기록을 유지합니다.

| 보상 | 기본 규칙 |
| --- | --- |
| 웨이브 클리어 | 기본 1~5웨이브 **100/130/160/190/220 노드**. 게임 시작마다 무작위로 정한 **2~5웨이브까지 +250 노드**를 추가합니다. 따라서 1·2웨이브는 **350/380 노드**, 디펜스 야생에서 핵심 무피해라면 **450/490 노드**입니다. 6~20웨이브는 웨이브당 +60, 이후 제곱근 단계마다 +90. 예: 20웨이브 **1,120 노드**(무피해 보너스 제외) |
| 개인 처치 | 마지막 타격한 웨이브 적 **4마리마다 8 노드** |
| 보스 처치 | 접속 중 생존자마다 첫 보스 **150 노드**, 이후 보스 웨이브마다 **+75 노드**. OP가 조정할 수 있습니다. |
| 핵심 무피해 | 디펜스 야생에서 웨이브 동안 핵심이 피해를 받지 않으면 생존자마다 **100 + (웨이브−1)×10 노드**를 추가로 받습니다. 수리해도 이미 받은 피해 기록은 지워지지 않습니다. OP가 조정할 수 있습니다. |
| 마력 주입자 | 일반 웨이브 몬스터마다 기본 **1%** 확률로 보라색 특수 개체가 등장합니다. OP가 H 관리자 설정에서 0~100%로 바꿀 수 있습니다. 직접 처치한 플레이어에게 마력 주입 기회 1회를 정상 클리어 때 지급합니다. 인챈트 책은 지급하지 않습니다. |

노드와 마력 주입 기회는 **웨이브 정상 클리어 때만** 확정 지급합니다. 적을 반복 생성하거나 디스폰시켜 처치 보상을 파밍할 수 없습니다. 기회는 계정에 저장되며 HUD에 남은 횟수가 표시됩니다. 인챈트할 무기 또는 방어구를 **주 손에 직접 들고 J**를 누르면 해당 장비에 호환 가능한 무작위 인챈트 1개를 붙입니다. 착용 중인 방어구와 보조 손 장비는 선택되지 않으며, 키를 누르기 전에는 자동 적용되지 않습니다. 이미 붙은 인챈트가 다시 선택되면 최대 단계까지 **날카로움 I → II**처럼 1단계 올라갑니다. 적용 가능한 인챈트가 없으면 기회가 차감되지 않습니다. 개인 클리어 보상은 팀 인원수만으로 증가하지 않습니다.

## 상점과 지속 업그레이드

K/H 상점은 **키오스크형 카드 화면**입니다. 상단에 지속 업그레이드를 고정하고 좌우 화살표로 넘깁니다. 하단은 **음식 / 유용한 아이템 / 방어구 / 건축** 탭으로 나누며, 탭 안의 상품은 현재 가격이 낮은 순으로 표시합니다. 방어구 탭에는 무기도 포함됩니다. 각 카드에는 바닐라 아이템 그림, 이름, 가격과 그림 아래 **구매 버튼**이 있습니다. 업그레이드 레벨과 남은 재고도 카드에 표시하며, 카드에 마우스를 올리면 다음 효과·설명을 볼 수 있습니다. 해금·잔액·재고·가격은 서버가 검사합니다.

업그레이드 페이지 전환 중 발생하던 상태 패킷 길이 오류를 수정했습니다. 상점 화면을 준비하거나 표시하는 중 예기치 않은 오류가 발생하면 게임을 종료하는 대신 **「상점 정보를 불러올 수 없음」**을 표시합니다. `ESC`로 진행 화면에 돌아갈 수 있으며 자세한 오류는 클라이언트 `logs/latest.log`에 기록됩니다. 이 안내는 상점 화면에서 처리할 수 있는 오류에 적용됩니다.

| 철 / 다이아 장비 꾸러미 | **2,000 / 18,000 노드**, 1/12웨이브 해금 |
| 토템 / 마법 황금 사과 | **3,200 / 5,500 노드**, 20/30웨이브 해금, 각 웨이브 1회 |
| 종결 네더라이트 장비 | **10,000,000 노드**, 40웨이브 해금, 웨이브당 1회 |
| 추가 생존·전투 상품 | 구운 감자×16 **45**, 황금 당근×8 **150**, 꿀병×4 **120**, 활 **250**, 쇠뇌 **850**, 분광 화살×24 **600**, 물 양동이 **180**, 엔더 진주×2 **900**, 철 도끼 **420**, 다이아 검 **3,500** 노드. 강한 상품은 해금 웨이브와 재고 제한을 적용합니다. |
| 추가 건축·함정 상품 | 비계×32 **180**, 철창×32 **250**, TNT×4 **950**, 달콤한 열매 덤불×16 **110**, 뾰족한 점적석×32 **130** 노드. TNT는 10웨이브부터 웨이브당 2회입니다. |

구매한 지속 효과는 무한 유지하며 사망·재접속·차원 이동 후 계정 단계에서 복원합니다. 방어·공격 능력치는 고정 ID 수정자를 사용해 중복 누적을 막습니다. 회복 업그레이드는 10초마다 체력을 회복하고 3·5단계에서 재생 I·II가 추가됩니다. 장비 자체는 일반 바닐라 내구도·사망 규칙을 따릅니다.

## 디펜스 야생 자동 포탑

**디펜스 야생 월드에서만** 상점의 **건축** 탭에 자동 사냥 포탑·포탑 강화·포탑 수리가 나타납니다. 일반 야생에서는 구매할 수 없습니다. 1웨이브부터 **400노드**로 거점의 **네 감시탑 지붕** 중 플레이어에게 가까운 빈 자리에 팀 포탑 1기를 설치할 수 있으며, 최대 4기입니다. 포탑은 아래부터 **상자·철창 받침·발사기**로 보입니다. 설치 위치에 다른 블록이 있으면 구매가 거절되고 노드는 차감되지 않습니다.

포탑은 진행 중인 웨이브 적만 조준하고, 벽 너머 적이나 일반 야생 몬스터를 공격하지 않습니다. 감시탑과 생성 지점 사이 거리를 반영해 **1단계는 공격력 1·사거리 30블록·60틱 간격**으로 조정했습니다. 발사선은 발사기 윗부분에서 적까지 확인합니다. 1웨이브부터 **250 / 450 / 810… 노드**로 팀 포탑 중 레벨이 가장 낮은 1기를 강화할 수 있습니다. 강화할 때마다 기본 공격력 +1·사거리 +3블록·발사 간격 −12틱이며, 사거리는 서버 부하를 고려해 최대 64블록, 발사 간격은 최소 10틱입니다. 강화 단계 제한은 없고 비용은 기본적으로 단계마다 ×1.8입니다. 가격·성능 수치는 OP 설정에 따릅니다. 강화 비용은 구매자 개인 잔액에서 차감됩니다. 적 처치 전리품은 해당 포탑 아래 상자에 들어가고, 상자가 가득 차면 남은 물품은 땅에 떨어집니다. 포탑 처치는 웨이브 클리어에 반영되지만 개인 처치 보너스와 직접 처치 인챈트 기회는 주지 않습니다.

상자·받침·발사기 중 일부가 파손되면 그 포탑은 멈춥니다. 1웨이브부터 **200노드**로 파손된 포탑 1기를 수리할 수 있습니다. 수리 가능한 자리에 다른 블록이 있으면 먼저 치워야 합니다. 포기·게임 종료로 새 게임을 준비하면 포탑의 받침과 발사기는 제거되지만 **상자와 안의 전리품은 남습니다**. 다음 게임에서는 노드로 포탑을 다시 구매할 수 있습니다.

## 디펜스 야생 기지 핵심과 성벽

디펜스 야생 거점 중앙 봉화는 **기지 핵심**입니다. 기본 체력은 **200**이고 H 진행 화면과 화면 **오른쪽 위 HUD**에서 확인할 수 있습니다. 웨이브 몬스터는 기본적으로 중앙 핵심으로 이동하고, 몹에서 **12블록 이내**에 살아 있는 플레이어가 있으면 플레이어를 우선 공격합니다. 플레이어를 공격하는 동안은 핵심에 접촉 피해를 주지 않습니다. 성벽의 지정된 돌 블록은 제한된 속도로 부술 수 있습니다. 공성 거한·파멸 기사는 핵심에 주는 피해가 큽니다. 일반 야생 월드에는 기지 핵심 패배 규칙이 적용되지 않습니다. 웨이브가 시작될 때 거점에서 72블록 넘게 떨어졌거나 다른 차원에 있는 참가자는 거점으로 돌아옵니다. **기지 안 바닥의 드롭 아이템**은 그때 정리하지만 인벤토리·상자 내용물은 유지됩니다.

팀원이 전멸하거나 **기지 핵심 체력이 0이 되거나 봉화가 파괴되면 게임 오버**입니다. 게임 오버 후에는 기존처럼 포기 투표 또는 OP 명령으로 새 게임을 준비할 수 있습니다. 진행 중 플레이어가 봉화를 직접 캐는 행동은 막지만 폭발 등으로 봉화가 사라지면 패배합니다. 새 게임을 시작하면 핵심과 체력이 복원됩니다.

건축 탭의 **기지 강화**는 기본 **600노드**부터 시작해 단계마다 ×1.8 가격으로 증가합니다. 단계마다 핵심 최대 체력 **+50**과 성벽 파괴 간격 증가를 얻으며 현재 체력도 가득 회복됩니다. **중앙 핵심 수리**는 **250노드**에 체력 **40**을 회복하고, **성벽 수리**는 **300노드**에 빈 성벽 자리 최대 **24블록**을 복구합니다. 수리 상품은 각각 기본 **웨이브당 2회**이며 해당 수치와 상품 해금/가격/재고는 OP 관리자 설정에서 바꿀 수 있습니다.

## 팀 공유 부활

팀 전체가 하나의 부활 횟수를 공유합니다. **새 웨이브가 시작할 때마다** 현재 웨이브와 참가 인원 기준으로 새 횟수로 초기화합니다. 초반은 1·2인 **4회**, 4인 **5회**입니다. 치명타를 맞고 팀 횟수가 남아 있으면 서버가 즉시 1회를 차감하고, 실제 사망·인벤토리 손실 대신 **불사의 토템과 같은 구조 연출 및 재생·흡수·화염 저항 효과**로 살려 줍니다. 손에 토템을 들 필요가 없습니다. 15웨이브부터 상한이 낮아지고, 30웨이브부터 4인 팀도 **팀 전체 1회**가 됩니다. 횟수가 0이면 다음 사망은 기존 관전 규칙을 따릅니다. 웨이브를 클리어하면 생존자의 체력을 최대로 채우고 관전자가 된 팀원도 다음 웨이브에 복귀합니다. 팀원이 전원 탈락하면 게임 오버입니다. 적 소실 등으로 **같은 웨이브를 재시도**할 때는 소모한 부활 횟수를 다시 지급하지 않습니다. 잔여 횟수·탈락자·팀원은 월드에 저장됩니다.

## OP 설정

권한 2 이상의 OP는 **H → 관리자 설정**에서 `전투 / 보상 / 시간·부활 / 기지·포탑 / 상품 가격 / 상품 조건` 탭을 선택합니다. 항목을 눌러 숫자를 입력하거나 ± 버튼으로 조정할 수 있습니다. 허용 범위는 입력란 아래에 표시되고, 값은 서버가 검증하여 월드에 저장합니다. 전투 탭에는 적 수·체력·공격력·장비 확률·마력 주입 몹 확률, 새 몹 해금/배치 간격, 보스 주기·보스 웨이브 일반 적 비율·보스 단계 성장·전체 적 상한이 있습니다. 보상 탭에는 초중후반 보상·처치/보스 보상·강화 첫 비용/증가율이 있습니다. 시간·부활 탭에는 휴식 길이와 팀 부활 단계가 있습니다. 기지·포탑 탭에는 설치/수리 가격·강화 공식·포탑 성능·핵심 체력·성벽 파괴 간격이 있습니다. 상품 가격과 상품 조건 탭에서 개별 상품의 가격·해금 웨이브·웨이브당 재고를 바꿀 수 있습니다. **재고 0은 무제한 구매**입니다.

기존 명령도 유지합니다. 예: `/endlessdefense config infuser 5`는 마력 주입 몹 출현 확률을 5%로 바꿉니다. `/endlessdefense balance show`로 경제·휴식·야간·부활 설정을 볼 수 있습니다. 새 항목과 개별 상품 설정은 관리자 화면을 사용하세요. 설정 변경은 이후 계산과 구매부터 적용되며, 이미 생성된 몬스터·이미 지불한 가격에는 소급되지 않습니다. 새 설정에는 플레이어 우선 공격 거리, 무피해 보상, 포탑 사거리·발사 간격이 포함됩니다. 서버와 클라이언트는 모두 **0.12.0**을 사용해야 합니다.

| `/endlessdefense balance` 항목 | 기본값 | 허용 범위 |
| --- | ---: | ---: |
| `early`, `earlyStep`, `mid`, `late` | 100, 30, 60, 90 | 10~1000, 0~200, 0~300, 0~500 |
| `killEvery`, `killBounty`, `boss` | 4, 8, 150 | 1~50, 0~100, 0~2000 |
| `infuser` | 1% | 0~100%; `enchantDrop` 명령도 호환 별칭으로 사용 가능 |
| `earlyBonus` | 250 노드 | 0~1,000 노드; 게임 시작 시 무작위로 정한 2~5웨이브에 추가 |
| `restMinStep`, `restMaxStep`, `restMaxCap` | 2, 3, 180초 | 0~10, 0~15, 관리자 화면은 60~300 |
| `night`, `nightCap` | 15%, 16마리 | 0~25%, 0~32 |
| `respawnCap`, `lateWave` | 8, 30 | 1~20, 10~200 |

예: `/endlessdefense balance early 100`. 기존 명령은 호환용으로 유지되고, 새 수치와 개별 상품 가격은 관리자 화면에서 조정합니다. 가격·보상·웨이브 공식은 각 설정값을 서버에서 읽어 적용합니다.
